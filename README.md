# Local Drivers Network

**The ride home small-town America lost — sold to towns as DUI prevention.**

A local driver/passenger network for small towns that lost their taxi companies and their Uber drivers to the nearest metro. The town gets the software free and pays **$1,000/month**; its own committee recruits local drivers, who bill passengers directly and keep **100% of the fare**; insurance and licensing run through **HUM** on a per-passenger-mile basis instead of ~$1,200/month commercial cover.

- **Investor:** Marry O. (2-year noncompete + terms of responsibility signed)
- **Version 1.0:** driver/passenger apps, under contract with **LUSTRA LABS**, quoted **$35,000 to market** (App Store + Google Play)
- **Version 2.0:** AI research engine (Rene Turcios) that screens ~3,700 in-band US towns, then files public records requests to build each qualifying town's own DUI cost case
- **Status (2026-10-20):** Brief + investor summary complete; sourced estimates verified; V2.0 build price open

## The numbers that matter

| | |
|---|---|
| Verified market funnel | 19,500 incorporated places → **~3,700** in the 5,000–40,000 band → **~900–1,400** also 1+ hr from a major city → **~550–850** need-qualified |
| Serviceable market | **~700 towns × $12,000/yr = $8.4M ARR** (ceiling: $44.4M ARR) |
| What one DUI costs taxpayers | **~$2,700** (CA courts study, inflation-adj.) to **$6,470** (WA 2023 cost model), 2–6 officer hours |
| A 12,000-person town's DUI burden | ~37 DUIs/yr → **$100K–$240K/yr** in public processing cost vs. a $12,000/yr fee |
| Proof the model works | WI Road Crew: alcohol crashes **−17%**, $15,300 per avoided crash vs. ~$56,000 crash cost. SafeRide: **1M+ rides since 2004** |
| Unit economics (modeled) | $12,000/yr per town, ~62–75% gross margin, CAC ~$1,600–$2,950, payback ~2–5 months |
| Capital to first revenue | $35,000 build + modeled **~$180K–$230K** total path (research rollout, pilots, legal/insurance, runway) + V2.0 build (TBD) |
